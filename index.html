02 — Findings
研究 成果
已公开的漏洞分析报告、技术文章与开源工具，来自成员日常研究积累。
CVE-2024-38193 NOV 2024 CRITICAL · 9.8
Windows AFD 驱动竞争条件导致本地提权
Windows Ancillary Function Driver (afd.sys) 中存在 UAF 漏洞，攻击者可通过 IOCTL 调度路径中的竞争条件触发，结合堆喷射技术将权限提升至 SYSTEM。完整分析包含 PoC 与补丁对比。
by 0xVOID 完整报告 
// afd.sys — vulnerable dispatch
AfdDispatch(PIRP Irp) {
  ctx = AfdGetContext(Irp);
  // [UAF window opens here]
  if (ctx->state == AFD_CONNECTED) {
    ctx->callback(ctx); // ← trigger
  }
}

Advisory AUG 2026 HIGH · 8.1
OpenSSL FIPS 模块 RSA 解密路径时序侧信道
OpenSSL 3.x FIPS 模块 RSA 实现中，CRT 重组步骤存在统计上可测量的时序差异，远程攻击者可利用此侧信道逐步恢复私钥材料。
